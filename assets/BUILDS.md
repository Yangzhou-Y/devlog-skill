# 产物登记

> 构建产物、报告、数据集往往不进版本库（或被忽略），它们的“身份”由这张表保证。
> 每次产生新的产物就登记一行；日志里一律用 ID 指认，不写“新版本”。

| ID | 类型 | 文件 | 时间 | 校验和 | 来源 | 备注 |
|---|---|---|---|---|---|---|

## 登记办法

```bash
python scripts/collect_evidence.py --date YYYY-MM-DD
```

脚本会列出当天新增的产物并算好 sha256，直接抄进上表。文件名、时间、校验和三者齐全才算登记完成。

## 类型取值

`位流` / `安装包` / `时序报告` / `测试报告` / `数据集` / `图件` / `脚本产物`

## 与提交的关系

代码用 commit 短哈希指认；仓库还没有提交时，日志的 `commits` 字段留空，并在「待补」里写“仓库尚未提交”。
